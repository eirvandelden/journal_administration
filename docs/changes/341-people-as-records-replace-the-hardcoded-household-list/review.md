- [x] Important: `resolve_by_account_name` adds a new import heuristic that the plan does not describe ("retain existing scope semantics"). The final `find_by(name: match)` is also not scoped to `own`, so an external account with the same name can win. Account names are not unique — `app/models/concerns/resolvable.rb:51` → fixed (Skip blank household identifiers and scope name resolution to own accounts); dismissed for the heuristic itself: the accepted Proof test `resolves a migrated household account from an import description` requires name matching, and it now only matches household accounts
